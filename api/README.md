# APIs

Esta trilha aplica JavaScript, TypeScript e Node em fronteiras HTTP.

## Etapas

1. requisição e resposta HTTP;
2. recursos e rotas REST;
3. códigos de status;
4. validação de entrada;
5. tratamento uniforme de erros;
6. autenticação e autorização;
7. persistência;
8. paginação, filtros e idempotência;
9. testes de integração;
10. observabilidade básica.

Uma API não está concluída apenas porque responde. Ela precisa validar dados, preservar regras, comunicar falhas e possuir testes verificáveis.
