# TypeScript

Esta trilha começa depois dos fundamentos de JavaScript.

## Etapas

1. tipos primitivos, objetos e funções;
2. união e narrowing;
3. interfaces e aliases;
4. generics;
5. tipos utilitários;
6. contratos entre camadas;
7. dados externos como `unknown`;
8. validação em tempo de execução.

TypeScript descreve o código durante o desenvolvimento. Dados recebidos de formulário, arquivo ou API ainda precisam ser validados durante a execução.
