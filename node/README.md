# Node.js

A trilha de Node trata o ambiente servidor, não apenas a execução de arquivos JavaScript.

## Etapas

1. módulos e configuração do projeto;
2. sistema de arquivos;
3. eventos e buffers;
4. streams;
5. variáveis de ambiente;
6. tratamento de falhas;
7. testes;
8. encerramento seguro de processos.

Os exercícios devem separar entrada, regra de negócio e saída. Essa separação prepara o código para APIs e serviços maiores.
