# Estudos anteriores

As pastas `aula04` até `aula16`, além de `aula12ex` e `aula14ex`, foram mantidas sem alteração.

Elas registram os primeiros estudos de JavaScript no navegador:

| Pastas | Assuntos predominantes |
|---|---|
| `aula04` a `aula10` | introdução, valores, DOM e eventos |
| `aula11` e `aula12` | condições |
| `aula12ex` | exercícios com DOM |
| `aula13` e `aula14` | repetições |
| `aula14ex` | exercícios com repetições e interface |
| `aula15` | arrays |
| `aula16` | funções |

Esse conteúdo representa histórico. Os exercícios novos usam nomes baseados no assunto e critérios de aceite, facilitando busca, revisão e apresentação profissional.
