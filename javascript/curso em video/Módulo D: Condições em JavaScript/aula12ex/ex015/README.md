# Exercício 015

Página que identifica o período do dia automaticamente a partir da hora do computador.

## Arquivos

- `exercicios.html` — estrutura da interface.
- `estilo.css` — estilos da página.
- `script.js` — regra que define a saudação e a aparência do exercício.
- `img/` — imagens usadas para manhã, tarde e noite.

## Funcionamento

Ao carregar, o JavaScript consulta a hora atual. A página escolhe uma mensagem, uma imagem e uma cor de fundo de acordo com o período encontrado.

## Conceitos praticados

`Date`, condições encadeadas, objeto para organizar caminhos de imagens e manipulação do DOM.
