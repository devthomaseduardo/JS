# Exercícios da Aula 12

Esta pasta reúne exercícios com interface completa, separando HTML, CSS e JavaScript.

## Estrutura

- `ex014/` — estrutura de página com lógica baseada no horário atual.
- `ex015/` — saudação automática que altera mensagem, imagem e cor de fundo conforme o período do dia.
- `modelo/` — exercício de verificação de idade e sexo com validação dos campos e seleção de imagem.

## Objetivo

Aplicar condições em situações visuais, conectando regras JavaScript ao conteúdo e à aparência da página.
