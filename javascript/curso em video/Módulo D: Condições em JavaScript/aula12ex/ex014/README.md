# Exercício 014

Exercício com página HTML, folha de estilos e JavaScript separados.

## Arquivos

- `exercicios.html` — estrutura da interface.
- `estilo.css` — aparência da página.
- `script.js` — consulta a hora atual e escolhe mensagem, imagem e cor de fundo conforme manhã, tarde ou noite.

## Conceitos praticados

- `Date` e `getHours()`;
- condições encadeadas;
- `querySelector()`;
- alteração de `textContent`, `src` e estilo pelo JavaScript.

O script referencia imagens por caminhos relativos, portanto esses recursos precisam existir para que a troca visual seja exibida.
