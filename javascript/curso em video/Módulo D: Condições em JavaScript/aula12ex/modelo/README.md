# Modelo de exercício

Exercício de verificação de idade e sexo com atualização dinâmica da interface.

## Arquivos

- `exercicios.html` — formulário para ano de nascimento e sexo.
- `estilo.css` — apresentação visual.
- `script.js` — valida os dados, calcula a idade, classifica a faixa etária e escolhe uma imagem.

## Regras praticadas

O script valida campo vazio, ano futuro, idade fora do intervalo esperado e ausência de seleção. Depois utiliza condições encadeadas para classificar criança, jovem, adulto ou idoso.

Este exercício combina validação de entrada, cálculos, condições e manipulação do DOM em uma única funcionalidade.
