# Módulo D: Condições em JavaScript

Este módulo trabalha decisões no fluxo do programa.

## Conteúdos praticados

- condição simples com `if`;
- condição composta com `if/else`;
- condições encadeadas com `else if`;
- operadores relacionais e lógicos;
- datas e horários com `Date`;
- seleção de casos com `switch`;
- aplicação de condições em páginas que manipulam o DOM.

## Estrutura

- `aula11/` — condições simples e compostas.
- `aula12/` — condições encadeadas, horários e dias da semana.
- `aula12ex/` — aplicações práticas com interface HTML, CSS e JavaScript.
