# Aula 12

Exercícios com condições encadeadas e seleção entre vários casos.

## Exercícios

### `ex011.js`

Classifica a situação de voto a partir de uma idade usando `if`, `else if`, `else` e operador lógico `||`.

### `ex012.js`

Obtém a hora atual com `Date` e escolhe uma saudação para madrugada, manhã, tarde ou noite.

### `ex013.js`

Obtém o dia da semana e usa `switch` para transformar o número retornado por `getDay()` no nome correspondente.

## Execução

Os arquivos podem ser testados pelo terminal com Node.js.
