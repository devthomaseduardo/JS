# Aula 11

Exemplos de decisões com `if` e `if/else`.

## Arquivos

### `008.js`

Verifica uma velocidade definida no código e informa quando ela ultrapassa o limite usado no exercício.

### `009.js`

Compara o país informado no código com `Brasil` para demonstrar uma condição composta.

### `008.html`

Versão com interface para digitar um país e exibir o resultado da verificação de nacionalidade no DOM.

### `ex010.html`

Cria uma interface de sistema de multas. A função lê a velocidade digitada e informa se o valor ultrapassa 80 km/h.

## Objetivo

Entender como uma condição decide quais instruções serão executadas de acordo com um valor.
