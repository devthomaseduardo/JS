# Aula 16

Introdução a funções com parâmetro e retorno.

## Arquivo

### `funcao.js`

Define a função `parimpar(n)`, que recebe um número e utiliza o resto da divisão por 2 para determinar se ele é par ou ímpar. A função retorna uma string e o resultado é exibido no console.

## Conceitos praticados

- declaração de função;
- parâmetro;
- condição dentro de uma função;
- operador `%`;
- `return`;
- chamada de função.

Execute com `node funcao.js` para visualizar o resultado.
