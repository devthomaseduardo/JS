# Módulo F: Avançando os estudos em JavaScript

Este módulo reúne conceitos que ajudam a organizar e reutilizar dados e comportamentos.

## Conteúdos praticados

- criação e alteração de arrays;
- `sort()`, `push()` e `length`;
- acesso a valores por índice;
- percurso de vetores com repetição;
- declaração e chamada de funções;
- parâmetros e retorno;
- operador de resto `%`.

## Estrutura

- `aula15/` — arrays e percurso de vetores.
- `aula16/` — funções com parâmetro e valor de retorno.
