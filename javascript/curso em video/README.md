# JavaScript - Curso em Vídeo

Esta pasta reúne os exercícios desenvolvidos durante o curso de JavaScript do Curso em Vídeo. O conteúdo está organizado por módulos e aulas para registrar a evolução dos estudos, desde os primeiros comandos até arrays e funções.

## Módulos

- Módulo A: Conhecendo o JavaScript — primeiros comandos, alertas e entrada de dados.
- Módulo B: Comandos Básicos do JavaScript — variáveis, conversão de tipos, strings e operadores.
- Módulo C: Entendendo o DOM — seleção de elementos, eventos e manipulação da página.
- Módulo D: Condições em JavaScript — decisões com `if`, `else`, `else if` e `switch`.
- Módulo E: Repetições em JavaScript — estruturas `for`, `while` e exercícios com repetição.
- Módulo F: Avançando os estudos em JavaScript — arrays, percursos em vetores e funções.

## Como executar

Os exercícios em HTML podem ser abertos diretamente no navegador. Os arquivos JavaScript voltados ao terminal podem ser executados com Node.js usando `node nome-do-arquivo.js`.

Cada pasta possui um README próprio com o objetivo dos exercícios e os principais conceitos praticados.
