# Aula 06

Exercícios introdutórios sobre variáveis, tipos de dados e strings.

## Exercícios

### `ex002.html`

Solicita o nome do usuário e monta uma mensagem de boas-vindas usando o valor armazenado em uma variável.

### `ex003.html`

Recebe dois valores, converte as entradas para `Number`, realiza uma soma e apresenta o resultado com template string.

### `ex004.html`

Recebe um nome e demonstra recursos de strings, como `length`, `toUpperCase()` e `toLowerCase()`.

## Objetivo

Praticar entrada, armazenamento, conversão e apresentação de dados antes de avançar para estruturas de decisão e manipulação do DOM.
