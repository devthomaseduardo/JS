# Módulo B: Comandos Básicos do JavaScript

Este módulo trabalha os fundamentos necessários para receber, transformar e apresentar dados com JavaScript.

## Conteúdos praticados

- declaração e uso de variáveis;
- entrada de dados com `prompt()`;
- conversão de texto para número com `Number()`;
- operadores aritméticos;
- template strings;
- propriedades e métodos de strings.

## Estrutura

- `aula06/` — exercícios de variáveis, soma de números e manipulação de textos.

A ideia central é perceber que dados recebidos pelo navegador precisam ser tratados de acordo com o tipo de operação que será realizada.
