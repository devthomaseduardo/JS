# Aula 09

Introdução ao DOM e à seleção de elementos HTML com JavaScript.

## Exercício

### `ex005.html`

Seleciona o segundo parágrafo da página com `getElementsByTagName('p')[1]` e escreve o conteúdo textual desse elemento usando `innerText`.

## Objetivo

Entender que o navegador representa o documento HTML como uma estrutura acessível pelo JavaScript e que elementos podem ser encontrados, lidos e posteriormente modificados.
