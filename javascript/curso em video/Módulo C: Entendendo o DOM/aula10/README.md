# Aula 10

Exercícios de eventos e interação com elementos do DOM.

## Exercícios

### `ex006.html`

Registra eventos de clique, entrada e saída do mouse em uma área da página. Cada evento chama uma função que altera texto ou estilo do elemento.

### `ex007.html`

Lê dois campos numéricos, converte seus valores para número, calcula a soma e atualiza o resultado diretamente no HTML.

## Objetivo

Praticar a ligação entre ações do usuário, funções JavaScript e atualização dinâmica da interface.
