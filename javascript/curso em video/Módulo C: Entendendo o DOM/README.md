# Módulo C: Entendendo o DOM

Este módulo introduz a manipulação de elementos HTML por JavaScript usando o DOM.

## Conteúdos praticados

- seleção de elementos por tag e por `id`;
- `getElementsByTagName()`;
- `getElementById()`;
- `querySelector()`;
- leitura e alteração de conteúdo;
- eventos de mouse;
- funções associadas a eventos;
- leitura de valores de campos de formulário.

## Estrutura

- `aula09/` — primeiros acessos a elementos da página.
- `aula10/` — eventos DOM e interação com campos HTML.

Nesta etapa, o JavaScript deixa de atuar apenas com caixas de diálogo e passa a controlar diretamente o conteúdo da interface.
