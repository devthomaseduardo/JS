# Módulo A: Conhecendo o JavaScript

Este módulo registra o primeiro contato com JavaScript no navegador.

## Conteúdos praticados

- uso da tag `<script>` em uma página HTML;
- `window.alert()` para exibir mensagens;
- `window.confirm()` para solicitar uma confirmação;
- `window.prompt()` para receber texto do usuário;
- relação entre HTML, CSS e JavaScript em um mesmo arquivo.

## Estrutura

- `aula04/` — primeiro exercício prático com interação pelo navegador.

O foco desta etapa é entender onde o JavaScript é executado e como uma página pode interagir com o usuário.
