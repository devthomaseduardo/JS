# Aula 04

Primeiro exercício do curso executando JavaScript dentro de uma página HTML.

## Exercício

### `ex001.html`

Apresenta uma página simples com o clássico "Olá, mundo!" e utiliza três recursos do navegador:

- `alert()` para mostrar uma mensagem;
- `confirm()` para receber uma confirmação;
- `prompt()` para solicitar uma informação.

## Objetivo

Entender como inserir JavaScript no HTML e observar a execução sequencial dos comandos no navegador.

Para testar, abra `ex001.html` em um navegador.
