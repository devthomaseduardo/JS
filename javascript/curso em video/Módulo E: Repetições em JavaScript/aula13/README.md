# Aula 13

Introdução às estruturas de repetição.

## Exercício

### `ex0015.js`

Executa uma contagem de 1 até 4 usando `for`. O arquivo também mantém um exemplo comentado de repetição com `while` para comparação entre as duas estruturas.

## Objetivo

Entender as três partes principais de um laço: valor inicial, condição de continuidade e atualização do contador.
