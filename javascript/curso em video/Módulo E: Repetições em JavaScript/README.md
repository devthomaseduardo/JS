# Módulo E: Repetições em JavaScript

Este módulo apresenta estruturas usadas para executar um bloco de código várias vezes.

## Conteúdos praticados

- repetição com `while`;
- repetição com `for`;
- contador e incremento;
- repetição crescente e decrescente;
- validação antes de iniciar um laço;
- geração de conteúdo HTML durante uma repetição.

## Estrutura

- `aula13/` — comparação prática entre estruturas de repetição.
- `aula14/` — estudo da estrutura `for`.
- `aula14ex/` — exercícios de contagem e tabuada usando repetição.
