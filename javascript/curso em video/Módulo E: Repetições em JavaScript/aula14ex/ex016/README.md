# Exercício 016 - Contador

Aplicação que gera uma sequência numérica a partir de três valores: início, fim e passo.

## Funcionamento

O JavaScript verifica se todos os campos foram preenchidos e converte os valores para número. Se o passo for menor ou igual a zero, utiliza `1`. Depois decide entre contagem crescente e decrescente.

## Conceitos praticados

- leitura de campos do DOM;
- validação de entrada;
- conversão com `Number()`;
- `for` crescente e decrescente;
- atualização do `innerHTML`.

Arquivos principais: `exercicios.html`, `estilo.css` e `script.js`.
