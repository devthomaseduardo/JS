# Exercícios da Aula 14

Aplicações de repetição controladas por dados informados na interface.

## Estrutura

- `ex016/` — contador configurável com início, fim e passo.
- `ex017/` — gerador de tabuada de 1 a 10.

## Objetivo

Usar `for` em situações reais de interface, validando os dados antes do laço e apresentando cada resultado diretamente no DOM.
