# Exercício 017 - Tabuada

Aplicação que recebe um número e gera sua tabuada de 1 até 10.

## Funcionamento

O script valida o campo, converte o valor informado e utiliza um `for` para calcular cada multiplicação. Cada linha da tabuada é adicionada dinamicamente ao resultado da página.

## Conceitos praticados

- validação de formulário;
- conversão numérica;
- estrutura `for`;
- multiplicação;
- template strings;
- geração de HTML com JavaScript.

Arquivos principais: `exercicios.html`, `estilo.css` e `script.js`.
